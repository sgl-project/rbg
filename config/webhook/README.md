# Webhook configuration manifests

`manifests.yaml` is generated by `make manifests` from the
`+kubebuilder:webhook` markers in `api/workloads/`. Do not hand-edit it; the
next regeneration overwrites any manual changes.

The service name and namespace in the generated file are Kustomize
placeholders:

- `namespace: system` is replaced with the Kustomize `namespace:` value
  (for example `rbgs-system`) by the namespace transformer.
- `name: webhook-service` is prefixed with `namePrefix:` (for example
  `rbgs-webhook-service`) via the built-in nameReference transformer.

**Do not apply `manifests.yaml` directly.** Always render the full
installation manifests with:

```bash
kustomize build config/default
```

`caBundle` is intentionally left empty. The in-cluster controller
(`WebhookCertReconciler`) patches it at runtime using the self-signed CA
generated by `pkg/webhook.CertManager`.
